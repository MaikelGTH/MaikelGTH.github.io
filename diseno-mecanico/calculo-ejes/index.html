    Cómo se calcula

    Cada carga se descompone en componente media y alternante. Para fatiga se aplican los Kf a las tensiones nominales y se combinan con Von Mises; el axial alternante se divide entre kc = 0,85 para poder usar un único Se de flexión (Shigley, ec. 7-7):

    σ'ₐ = √[ (Kf·σb,a + Kf,ax·σax,a/0,85)² + 3·(Kfs·τa)² ]    σ'ₘ = √[ (Kf·σb,m + Kf,ax·σax,m)² + 3·(Kfs·τm)² ]

    Si la media normal resulta de compresión no penaliza la fatiga y solo cuenta la torsión media. El límite de fatiga se corrige con los factores de Marin (acabado mecanizado, tamaño con de = 0,37·d si la pieza no gira, carga y fiabilidad del 99 %):

    Se = kₐ·k_b·k_c·k_d·k_e·Se'    1/n = σ'ₐ/Se + σ'ₘ/Sut (Goodman)    1/n² = (σ'ₐ/Se)² + (σ'ₘ/Sy)² (ASME)

    La vida se estima con la recta de Basquin entre 0,9·Sut (o f·Sut en acero) a 10³ ciclos y Se a Ninf, usando la tensión totalmente alternante equivalente σrev = σ'ₐ / (1 − σ'ₘ/Sut). El FoS estático usa el pico nominal sin Kf, porque el material es dúctil.

    • El aluminio no tiene límite de fatiga real: Se' es la resistencia a 5·10⁸ ciclos y la «vida infinita» significa más de esos ciclos.
    • En tornillos manda la rosca: para un cálculo fino usa el Se de rosca (Shigley tabla 8-17) o VDI 2230. El titanio es casi totalmente sensible a la entalla: usa Kf ≈ Kt.
    • No se comprueba pandeo global ni pandeo local de pared (relevante a partir de D/t ≈ 30), ni velocidades críticas o deformaciones.
    • Flexión y axil alternantes se suman en fase, lo que es conservador si en realidad van desfasados.
